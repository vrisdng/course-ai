# office-converter

Converts DOCX/PPTX uploads to PDF with headless LibreOffice so they go through
the normal PDF ingestion pipeline (OCR by page range, embedding, page images,
citation highlights). Called only by `process-material-job`; see
`supabase/functions/_shared/officeConversion.ts` and HANDOFF.md
("Office documents → PDF").

- `POST /convert` with `Authorization: Bearer $CONVERTER_SECRET` and
  `{ "sourceUrl", "uploadUrl", "format": "docx" | "pptx" }`, both signed
  Supabase Storage URLs. Downloads the original, converts, `PUT`s the PDF.
  No Supabase credentials; refuses URLs outside `SUPABASE_URL`'s origin.
- `GET /health`.

## Deploy (its own Vercel project)

Vercel runs `Dockerfile.vercel` as a container function. Create a separate
project with **Root Directory = `services/office-converter`**, then set:

| Where | Variable |
|---|---|
| Vercel (this project) | `CONVERTER_SECRET`, `SUPABASE_URL` (`https://<ref>.supabase.co`) |
| Supabase secrets | `OFFICE_CONVERTER_URL=https://<converter-domain>/convert`, `OFFICE_CONVERTER_SECRET` (same value) |

Without the Supabase secrets, DOCX/PPTX keep the old XML text extraction.

## Run locally

```sh
docker build -f Dockerfile.vercel -t office-converter-local .
docker run -d --name office-converter-local --network supabase_network_<project_id> \
  -e CONVERTER_SECRET=local-secret -e SUPABASE_URL=http://kong:8000 office-converter-local
# functions env: OFFICE_CONVERTER_URL=http://office-converter-local/convert
```

Node 24 runs `src/*.ts` directly (type stripping), so code must stay
erasable-only (`tsconfig.services.json` enforces it). Tests run with `npm run test`.

## Known limits

- LibreOffice (Debian 12, 7.4) draws Word equations faithfully. PowerPoint
  equations rely on the picture PowerPoint stores alongside each one; files
  without it (e.g. generated by pandoc) convert with the equations blank.
- Layout can shift where documents use fonts that aren't installed; Carlito
  and Caladea stand in for Calibri and Cambria.
- Conversions on one instance run one at a time (shared LibreOffice profile).
